# UI‑автотесты для веб‑приложения «Самокат» (QA Scooter)


Автотесты для сервиса аренды самокатов на **Python + Selenium + Pytest + Allure**. Проверяют работу раздела «Вопросы о важном», оформление заказа и функциональность логотипов.

## Архитектура: Page Object Model (POM)


Проект использует паттерн **Page Object Model** — это значит, что:
* логика работы с UI вынесена в отдельные классы страниц;
* локаторы элементов и методы взаимодействия с ними сгруппированы по страницам;
* при изменении интерфейса правки нужны только в одном месте (в классе страницы или файле локаторов);
* код тестов становится чище и проще в поддержке.


**Структура:**
* `pages/base_page.py` — базовые методы (ожидание, клик, ввод текста и т. д.);
* `pages/*.py` — классы конкретных страниц (`questions_page.py`, `order_page.py` и др.);
* `locators/*.py` — файлы с локаторами элементов для каждой страницы.


## Файлы проекта (ключевые)

* ``url.py`` — URL приложения.
* ``requirements.txt`` — зависимости.
* ``helpers.py`` — генерация тестовых данных (Faker).
* ``data.py`` — ожидаемые ответы.
* ``conftest.py`` — фикстуры.
* ``test_*.py`` — тестовые сценарии.
* ``pages/`` — классы страниц.
* ``locators/`` — локаторы элементов.

## Реализованные тесты

* **Раздел «Вопросы о важном»**: проверка соответствия вопросов и ответов.
* **Оформление заказа**: заполнение форм, выбор параметров, проверка сообщения «Заказ оформлен».
* **Логотипы**:
  * клик на «Самокат» → переход на главную;
  * клик на Яндекс → открытие Дзена в новой вкладке.

## Запуск тестов

**Установка зависимостей:**

pip install -r requirements.txt

**Запуск:**


# Все тесты
pytest -v

# Отдельный файл
pytest test_questions_page.py -v

**Отчёт Allure:**

pytest --alluredir=allure-results
allure serve allure-results
